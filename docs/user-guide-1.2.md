# Video Save · 网页视频保存助手 1.2.0

鼠标停在视频画面、视频封面或视频链接上，按 **Ctrl+C** 下载。未点开的条目会在后台解析，不需要把当前页面跳转到播放器。文件统一写入你选定的“视频”文件夹内的 **VideoDownloads** 子目录。

## 从 1.1.0 升级

1. 用新包的 `extension` 文件夹内容替换原目录，或直接使用本项目已更新的 `extension`。
2. 打开 `edge://extensions`，点击插件的 **重新加载**，确认版本为 **1.2.0**。
3. 点击插件图标，点击面板上方的 **选择视频文件夹**。选择器默认打开系统 **视频** 位置，选定一次并允许写入。
4. 刷新要使用的网页一次。以后悬停视频或封面，按 **Ctrl+C** 即可。

当前插件目录：`C:\Users\lenovo\Documents\ChatGPT\edge 2\extension`。

## 系统“视频”位置

浏览器的普通下载接口只能指定下载目录内的相对路径，不能直接指定 Windows“视频”的绝对路径。1.2.0 改为使用浏览器的目录选择与文件写入 API，只改变本插件的文件位置，不修改 Edge 其他下载的默认目录，不需要安装本地助手。

- 选择系统“视频”目录后，输出到 **视频 / VideoDownloads**。
- 如果选择的本身就是 VideoDownloads，直接使用它，不创建嵌套目录。
- 选择的目录句柄保存在本扩展自己的 IndexedDB，重新打开面板仍保留。
- 浏览器权限被撤销或浏览器要求重新授权时，面板会提示重新选择；不偷偷改存到“下载”目录。
- 同名文件自动加编号，不覆盖已有文件；取消会中止临时写入。
- 普通视频采用流式写盘，不必先把完整文件装进内存。B站合并和 Blob 仍有 384 MiB 的内存处理上限。

文件直接写入所选目录，**不再作为浏览器原生下载显示在 Edge 下载记录中**。请到 Windows“视频 / VideoDownloads”查看。

## 哪些“手形”条目能下载

- B站普通 BV / av 视频封面链接，以及常见 b23.tv 短链接。
- 指向 MP4、WebM、OGV、MOV 等视频文件的链接。
- 带缩略图或明确视频标识的常见 `/watch`、`/video`、`/videos`、`/play` 详情页链接。插件会后台打开详情，等待主视频资源，避免只保存先出现的小预览。
- 已打开的 HTML5 视频、可读取的真实视频 Blob、播放器覆盖层与开放 Shadow DOM 中的视频。
- HTTP(S) iframe 中的可识别视频和链接。

鼠标呈手形也可能只是普通导航、点赞、广告按钮；插件不会把它们全当视频。纯 JavaScript 按钮如果既没有真实链接也没有视频地址，无法通用解析，需要针对具体网站适配。通用 HLS/DASH 分片流、直播、DRM、番剧与课程暂不支持。

## 快捷操作

在视频画面或封面上按 Ctrl+C，网页右下角显示任务提示；点击提示中的“取消”可停止。普通详情页和 B站会创建插件自己的后台解析/合并页，成功后自动清理。用户原有标签页不会被自动关闭。

输入框、可编辑区域或有文字选区时，Ctrl+C 保持正常复制。插件不读写剪贴板。地址栏、开发者工具、浏览器内置页和扩展商店等受保护页面无法使用网页快捷监听。

第一次目录未选时，任务面板会打开，完成目录选择后继续任务。后续无需每次选位置或画质。需要手动选择视频、分P、清晰度，或保存 B站音频和封面时，仍可点击工具栏图标打开面板。

## 常见问题

**按快捷键没有反应**：更新后刷新网页；确认没有文字选区，键盘焦点不在输入框或地址栏；鼠标停在封面的真实视频链接或视频画面上再试。

**封面被识别但解析失败**：网站可能尚未提供普通视频地址，或使用需要站点专用解析的分片播放器。插件不会自动点击网页按钮、提交表单或绕过观看权限。可打开视频后再试，或提供具体网址继续适配。

**B站 412 / 403 / 567**：插件保留播放器提供的首选和备用资源、原始签名参数，使用当前网页已有的观看权限。若页面或 CDN 对当前环境限制访问，仍可能失败；先确认网页能正常播放，再重试。

**合并视频过大**：B站音视频合计或 Blob 单文件超过 384 MiB 时，选择较低画质。普通直链流式保存不受该合并容量上限限制。

## 权限与隐私

- HTTP(S) 站点权限与 `scripting`：识别鼠标指向的视频和链接，在用户触发后解析资源；不监听网页网络流量。
- `storage`：会话任务状态存储在 session；选定目录句柄保存在本扩展的 IndexedDB。
- 文件夹写入权限由浏览器一次选择授予，不通过脚本或本地助手绕过。
- `declarativeNetRequestWithHostAccess`：仅用于扩展自身 hdslb 封面请求的 Referer。
- 不导出 Cookie、不读取或改写剪贴板、不上传视频、不提供统计或遥测。
- FFmpeg 脚本和 WASM 随包提供，不远程加载执行代码。

## 验证说明

- 21 项核心、快捷键、传输、目录写入、主视频发现与创建/取消竞态测试。
- 原有 14 项 B站面板场景，包括实际内容脚本传输、本地 WASM 合并、音频/封面、错误、取消与超限。
- 普通视频快捷测试包括 MP4、覆盖层 WebM、文本复制保护、Shadow DOM、Blob、跨域 iframe、取消与手动选择。
- 新卡片场景覆盖没有播放器的纯封面页、手形光标文件链接、延迟出现的主视频、先出现的小预览、B站链接保留分P、后台标签清理、普通导航忽略及解析中取消。
- 目录持久、重名与保存使用真实浏览器文件系统 API 验证；自动测试把操作系统目录选择器替换为隔离 OPFS 的 Videos 目录，**没有自动授予真实系统 Videos 权限**。
- B站测试使用受控接口与两秒测试流；不将它描述为所有真实 B站视频均已验证。此前公网测试环境访问 B站返回 412。公网普通 MP4 可用 MDN 官方示例进行独立实测。

## 开发

插件免构建；使用者不需要 Node、Python 或 FFmpeg。开发环境使用 Node.js 20+、Playwright 和本机 Edge，打包需 Python 3：

```powershell
node --test tests/core.test.mjs tests/transfer.test.mjs tests/quick.test.mjs tests/output.test.mjs tests/discovery.test.mjs tests/background-race.test.mjs
node tools/browser-test.mjs
node tools/quick-browser-test.mjs
node tools/cards-browser-test.mjs
node tools/cdn-regression.mjs
node tools/check.mjs
node tools/package.mjs
```

可用 `PLAYWRIGHT_PACKAGE` 指定 Playwright 模块路径；设置 `PUBLIC_VIDEO=1` 可对 MDN 官方公开示例 MP4 做真实网络保存测试。测试目录为 `.test/`，不读取个人浏览器配置。

第三方依赖、固定版本与许可证见 `extension/THIRD_PARTY_NOTICES.md`。原始调研与版本设计保留在 `docs/`。
