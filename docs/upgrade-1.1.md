# 1.1.0: hover + Ctrl+C and ordinary HTML5 websites

用户要求直接升级，无需再次讨论方案。保留 B站 MP4 合并，普通站点增加 HTML5 直链视频、可读取视频 Blob；鼠标悬停后 Ctrl+C 直接下载，所有成品统一使用浏览器下载目录内的 VideoDownloads 子文件夹。

Ctrl+C 仅网页获得键盘事件时可用，地址栏、浏览器内置页无法捕获。不读取剪贴板、不接管输入框、可编辑内容和有文字选区的复制；长按防重复。播放器覆盖层与开放 Shadow DOM 也参与命中。内容脚本在 HTTP(S) 页面与子框架监听，收到真实用户按键才发起下载，不监听网络流量。

普通直链使用浏览器原生下载，在后台完成；B站和 Blob 使用自动开始的后台扩展任务页。B站仍需保留来源页，关闭任务页会中断合并。任务接受、保存和错误通过来源页提示反馈。快捷触发不会弹出画质选择或保存对话框。默认使用当前账号可用的兼容画质。

先写规则与实际浏览器快捷键测试，再接入内容脚本、后台、任务页与目录。验证多视频鼠标选择、复制保护、覆盖层、Shadow DOM、子框架、重复按键、普通MP4/WebM、Blob、B站自动合并、固定目录和已有567回归。通用 HLS/DASH、DRM 和复杂站点专用解析不在本版支持范围，明确提示而不是生成错误文件。
