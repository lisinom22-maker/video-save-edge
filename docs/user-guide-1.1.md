# Video Save · 网页视频保存助手 1.1.0

纯 Edge 插件。**鼠标停在视频上，按 Ctrl+C，直接下载。** 支持普通网页视频和 B站普通视频，文件统一保存到浏览器下载目录内的 **VideoDownloads** 文件夹。不需要额外安装下载工具。

## 从旧版升级

1. 如果你之前加载的是本项目的 `extension` 文件夹，代码已经更新；如果用的是另一个解压目录，用新 ZIP 中的 `extension` 完整替换该目录内容。
2. 打开 `edge://extensions`，对插件点击 **重新加载**。新名称为 **Video Save · 网页视频保存助手**，版本 **1.1.0**。
3. 这版为了在其他网站捕获鼠标和按键，需要在普通 HTTP/HTTPS 网页运行。Edge 如果提示新的站点访问权限，需要允许后才能使用跨网站快捷键。
4. **刷新要下载视频的网页一次**，关闭旧版下载面板。
5. 此后只需把鼠标放在视频画面上，按 **Ctrl+C**。

当前项目插件目录：

`C:\Users\lenovo\Documents\ChatGPT\edge 2\extension`

首次安装：解压 ZIP → `edge://extensions` → 开启「开发人员模式」→「加载解压缩的扩展」→ 选择包含 `manifest.json` 的 **extension 文件夹**。不要直接加载 ZIP；保留文件夹，不要移动或删除。

## 日常使用

1. 打开网页，必要时先播放一下视频，使资源地址加载完成。
2. 鼠标停在要保存的视频上，按 **Ctrl+C**。
3. 网页右下角会显示下载提示。普通直链在浏览器后台下载；B站会自动选择默认可用画质，合并画面和声音；Blob 通过后台任务页保存。
4. 完成后显示「视频已保存到 VideoDownloads 文件夹」。重复文件名自动编号，不覆盖已有文件。

快捷下载不需要手动选择画质、打开面板或每次选择路径。需要取消时，点击网页提示中的「取消」。B站 / Blob 的后台任务页完成后会自动关闭；失败页保留，方便查看原因。

**B站与 Blob 下载时请保留来源网页，不要刷新或关闭它。** 普通 MP4 / WebM 原生下载开始后可以继续浏览。快捷键需要网页获得键盘事件；地址栏、开发者工具、Edge 内置页、扩展商店等受保护页面不在作用范围内。

## 不影响正常复制

以下情况 Ctrl+C 保持正常复制，不触发下载：

- 正在输入框、文本框或可编辑区域中操作。
- 页面上有文字选区。
- 鼠标没有指向可识别的视频。
- 使用了其他组合键，如 Ctrl+Shift+C。

插件不读取或改写剪贴板。长按 Ctrl+C 不会不断创建任务；正在下载的同一视频会去重。鼠标命中支持常见播放器覆盖层、开放 Shadow DOM，以及 HTTP(S) iframe 中的原生视频。

## 文件保存位置

所有由插件保存的成品都使用这个目录，包括快捷下载、手动面板、B站合并、音频和封面：

`浏览器当前下载目录 / VideoDownloads / 文件名`

例如 Edge 默认下载到 Windows 的「下载」文件夹，则结果位于「下载\VideoDownloads」。目录由浏览器自动建立。纯插件可以指定下载目录内的子文件夹，不能静默写入任意磁盘绝对路径。这里是跟随 Edge 当前下载目录的固定子目录，不是项目源码目录。

## 支持范围

| 类型 | 支持情况 |
| --- | --- |
| 普通 HTML5 MP4、WebM、OGV、MOV 直链 | 支持，保留原文件格式 |
| `<source>` 提供的视频地址、跨域视频直链 | 支持；服务器需允许普通下载请求 |
| 由真实视频文件创建的可读取 Blob | 支持，单次最多 384 MiB |
| B站普通 BV / av 视频 | 支持，自动合并带声音的 MP4 |
| B站分P与画质选择 | 快捷键保存当前分P、默认可用兼容画质；手动面板可选择 |
| 通用 HLS / DASH 分片流、直播 | 本版暂不支持 |
| MediaSource 播放器产生的 Blob | 普通网站暂不支持；B站走专用解析 |
| DRM、付费权限绕过、番剧与课程 | 不支持 |

B站使用当前网页账号本来能获取的画质，默认优先 H.264。高清或会员画质取决于账号权益。B站合并的音视频合计最多 **384 MiB**；普通原生直链下载不经过浏览器合并内存，因此不受该合并容量上限限制。

## 手动面板

点击工具栏插件图标即可打开手动面板：普通网站会列出识别到的视频，B站会列出分P和可用画质。手动下载同样保存到 VideoDownloads；B站保留仅音频与封面功能。

## 常见问题

**按 Ctrl+C 没反应**：更新后先刷新网页；确认键盘焦点在网页内、没有文字选区、没有正在编辑输入框；鼠标移到视频画面中央再试。可以点击插件图标进入手动面板检查是否识别到视频。

**提示分片流 / Blob 无法保存**：普通网页的 `blob:` 地址可能是 MediaSource 产生的分片播放器，不是完整视频文件。本版不将这种地址误当成 MP4。通用 HLS/DASH 需后续专门支持。

**B站 HTTP 567**：1.0.1 起已修复过滤掉播放器首选 Akamai 节点的问题；保留首选及备用地址、原始签名参数。个别 CDN 仍可能受地域或请求限制。

**HTTP 412 / 403 / 风控**：在来源网页确认视频能够正常播放，必要时正常登录、刷新并稍后重试。插件会尝试读取与视频及分P精确匹配的播放器现有信息。页面和接口都被限制时无法继续。

**没有需要的高清画质**：先确认网页播放器也有该画质，再通过手动面板重新识别。插件不提升账号权限。HEVC、AV1、HDR 和杜比视界需要相应解码与显示支持，优先 H.264 可获得较好的兼容性。

## 隐私与权限

- `scripting` 和 HTTP(S) 站点访问：检测网页视频、鼠标位置和符合条件的快捷键；B站需要请求站点播放信息。其他站点不使用 B站解析逻辑。
- `downloads`：保存用户主动触发的文件。
- `storage`：仅用 `storage.session` 记录当前浏览器会话中的任务与子框架状态，完成或取消后删除任务记录；不建立持久浏览历史。
- `declarativeNetRequestWithHostAccess`：仅为扩展自身发起的 hdslb 封面请求补充 Referer；不改写其他网站请求。
- 不监听网页网络流量，不读取/导出 Cookie，不读取/改写剪贴板，不上传视频，不提供遥测或统计。
- FFmpeg 的代码和 WASM 全部随包提供，运行时不远程加载代码。

## 已验证与限制

在全新隔离的本机 **Microsoft Edge** 中实际加载扩展，未接触个人浏览器配置。测试包括：

- 15 项核心与传输测试：签名、域名、画质、分P、分块完整性、取消、快捷键保护与路径清理。
- 原有 14 项 B站面板集成场景：实际 Port 传输、本地 WASM 合并、原生保存、音频、封面、网络错误、超限、未登录与缓存降级等。
- 普通网页测试：多个视频的精确选择、覆盖层 WebM、输入框与文字选区的复制保护、开放 Shadow DOM、真实 Blob、跨域 iframe、顶层提示取消，以及原生文件确实落入 VideoDownloads。
- B站快捷测试：Ctrl+C 自动创建后台任务、无手动操作合并 MP4、错误后立即重试，以及慢 API 解析阶段取消后不再发起媒体下载。
- 567 回归：首选 Akamai 可用、备用返回 567 时，保持播放器首选，音视频成功合并。
- 公网示例：通过 Ctrl+C 真实下载 MDN `<video>` 官方文档的公开示例 MP4，确认文件落入固定子目录、包含有效 MP4 文件头；没有模拟该公网视频的网络响应。来源：https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/video 。

受控 B站接口与两秒测试音视频只用于功能回归；真实 Worker、扩展 API 与文件保存均实际执行。真实 B站视频的完整下载仍未完成验证：此前隔离公网环境返回 HTTP 412，用户浏览器的自动调试又因无法可靠确认地址被安全检查停止。不会将这些回归测试描述成所有网站或所有 B站视频均可用。

## 开发

插件源码无需构建，使用插件不需要 Node、Python 或 FFmpeg。开发检查使用 Node.js 20+；ZIP 打包另需 Python 3：

```powershell
node --test tests/core.test.mjs tests/transfer.test.mjs tests/quick.test.mjs
node tools/browser-test.mjs
node tools/quick-browser-test.mjs
node tools/cdn-regression.mjs
node tools/check.mjs
node tools/package.mjs
```

浏览器测试需要 Playwright 与本机 Edge；可用 `PLAYWRIGHT_PACKAGE` 指定模块目录。测试音视频由本机 FFmpeg 生成，均放在 `.test/`。可选公网示例测试设置 `PUBLIC_VIDEO=1`，会下载 MDN 文档中的公开示例 MP4，而非使用模拟网络响应。

第三方依赖与许可证见 `extension/THIRD_PARTY_NOTICES.md`；设计与修复记录见 `docs/`。原创扩展代码独立实现，未复制 Bili-Mux 项目代码。
